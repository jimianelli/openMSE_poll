Evaluation of the SCA–OM walkthrough

Published

October 9, 2026

Scientific interpretation

The document provides a useful teaching sequence and visible code: input mapping, growth and maturity, SCA fitting, OM conditioning, and example MP comparisons. Its current evidence supports a demonstration of that sequence. A fit summary, four MP plots, and a successful render alone cannot establish that the OM reproduces the pollock assessment or that the MPs are ready for management use.

The review preserves the original scientific code. Corrections below are proposed changes for the next analytical revision; the historical render retains its original results and receives an explicit status notice.

Corrections in priority order

Priority Finding in the source Effect Proposed correction
1 R/mse2slick.R uses MSE@FM for PNOF and panels labelled F/FMSY. The plotted mortality and overfishing indicator use an absolute annual rate. Use MSE@F_FMSY, then regenerate and validate the Slick object and figures.
1 The walkthrough normalizes every fishery CAA row to sum to one; sam_fsh is read but unused. CV_Cat = 0.05 controls catch error. The original composition sample sizes are discarded. Build CAA from the agreed effective sample sizes and set CAA_multiplier explicitly; compare composition contributions and residuals.
1 SCA receives constant Mort = 0.3; the OM then receives M = 0.9, 0.45, and 0.3 for ages 1, 2, and 3+. The survival schedule changes after N and F have been estimated. Export M, N, F, weights, maturity, and age conventions from one coherent assessment run, or implement and validate the intended age-specific mortality in the assessment.
1 N_at_age and F-at-age from one fit are repeated into 48 simulations. The ensemble supplies repeated fitted histories rather than 48 independent assessment-uncertainty draws. Use validated posterior/bootstrap draws with their joint N–F–M–weight relationships intact. Separate future recruitment variability from historical estimation uncertainty.
1 wt_fsh is used for OM biomass and spawning weights; wt_ssb is loaded in the cache but omitted from conditioning. The biomass and spawning schedules can differ from the assessment. Define the spawning-biomass convention and assess support for separate spawning/fishery weights before bridging.
2 Growth is fitted to all-year mean weights; maturity is interpolated to length. Annual weight variation and the source maturity schedule are compressed. Preserve age-based schedules in the OM and compare implied SSB and catch with the reference run.
2 Survey vulnerability is fixed to 1 for every age and survey. BTS/ATS age compositions, ATS age-1 information, CPUE, and age error are omitted. The SCA is a simplified assessment with a narrower information set. Document the simplification and test survey selectivity and information subsets against Model 26.0.
2 The catch figure labels the stored series as metric tons; the terminal demo catch is 1300 on the assessment scale. Readers can interpret catches on the wrong scale. Label thousand metric tons and provide an explicit, checked conversion before comparing with tonne-based TACs.
2 The MPs are curEref, FMSYref, FMSYref75, and NFref. They provide benchmark contrasts; the document does not implement the pollock advice process. Add the specified NPFMC Tier 3 rule, annual assessment/advice timing, and fishery implementation assumptions. Keep oracle MPs as benchmarks.
2 No final gradient, Hessian evidence, saved assessment, or model/package version is linked to the displayed fit. The January results cannot be validated from the report alone. Save the assessment and diagnostics with source hashes, software versions, seed, and run configuration.
3 R scripts resolve here("openMSE", ...) although the folder is openMSE_poll; the .dat fallback uses an undefined dat_file. Execution depends on an earlier folder layout and a pre-existing RDS. Use explicit input arguments and a project-relative output path; validate cached input against its source fingerprint.
3 The document contains nested report generation, expensive fits, and simulations; it resets perf_tbl <- NULL before testing whether that object exists. Rendering is coupled to analysis, and the export can discard the prepared quilt table. Move model execution to an explicit analysis stage and let reports consume saved, validated output tables.

The MSE class documentation distinguishes FM from F_FMSY. The SAMtool SCA documentation defines the CAA sample-size weighting and CAA_multiplier behavior. AddInd = 1:3 selects the three additional indices: placing BTS in both Ind and AddInd does not itself establish duplicate fitting. The mapping table should be corrected to show BTS, ATS, and AVO in additional-index positions 1, 2, and 3.

Metric definitions and checks

Report each indicator with its unit, reference point, aggregation window, and whether it describes time within one simulation or frequency across simulations. The current PNOF calculation averages years within each simulation; label it accordingly. Evaluate depletion events, rebuilding time, short- and long-term yield, catch variability, and the probability of crossing agreed biomass limits.

The Slick converter averages RefPoint$MSY or falls back to a scalar mean. Current MSEtool documents annual reference points as arrays by simulation, MP, and year. Preserve those dimensions and align the final ten catch years with their matching MSY values. Fail on unrecognized dimensions instead of silently averaging them. Use spawning-biomass labels consistently for SB_SBMSY in the Kobe panel.

Validation gates

Gate Current evidence Status and required action
Track and scope Exploratory MSE working paper; original data end in 2024. Pass for a methods review; a current analytical application remains pending.
Source lineage File hashes and coverage audit; public Model 26.0 source checks. Pass for the reviewed inputs. Accepted annual input/run designation remains pending.
Model diagnostics A small base.rds stores time series and metadata; no gradient or Hessian record. Original SCA diagnostics unverified. A new fit must supply max gradient < 1e-4, positive-definite Hessian, finite SEs, and reviewed warnings.
Scientific consistency Mortality, composition weighting, spawning weights, and metric labels need work. Fail for use as a current assessment-conditioned MSE.
Rendering Fresh Quarto build of the review and audit; historical walkthrough identified separately. Review build verified; historical model execution not reproduced.
Accessibility Review HTML uses semantic headings, real tables, captions, and chart alt text. Source/structural checks performed; screen-reader and full WCAG/Section 508 validation not tested.

The January walkthrough lacks alt text for most analytical figures and uses color-based MP displays. Retain its historical status and add meaningful alt text, non-color encodings, and machine-readable figure data in the analytical revision.

The retained HTML also displays an unresolved fig-mse-metrics-plot reference, warnings from repeated maturity probabilities during interpolation, and long simulation progress logs. A conditional chunk produced no metric figure, leaving its cross-reference unresolved. Make missing-output handling explicit, review maturity interpolation, and keep routine progress in the run log. The historical run also reports that openMSE re-estimated growth from its age arrays (Linf about 61.46, K about 0.248), which differs from the supplied growth configuration; check the age origin and reproduction of the input length schedule during bridging.
